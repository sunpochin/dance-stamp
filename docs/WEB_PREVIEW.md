# 桌面 Web 預覽

使用者於 2026-10-27 指定先做 Web，暫不處理 iPhone。此版提供可操作的桌面流程，未公開發布，未完成整體 P0 驗收。

2026-10-28 桌面實作加入「比較已有影片」正式入口，包含各自選起點、不開相機、共同對齊及 VS 輸出，見 [產品流程 B2](PRODUCT_PLAN.md) 與 [#10 實測範圍](evidence/issue-10-existing-comparison.md)。原本「已有自拍原片？」仍供錄影原片恢復；兩條路徑分別驗收，不能以此宣告整體 P0 完成。

使用 Bun 1.4.4 先執行 `bun install --frozen-lockfile --ignore-scripts`，再執行 `bun run dev`，在此電腦開啟 `http://127.0.0.1:4173/`。`bun run build` 產出 `dist/web/` 靜態檔，不需要 API key、帳號或後端。

## 比較兩支既有影片

1. 點首頁「比較已有影片」，或開啟老師片後點「用這支老師片比較已有影片」。分別選左邊老師、右邊自己的原片，各自預覽並勾選確認；不要求相機或麥克風。
2. 各自選同一動作起點：老師 A、自己 C，再選老師結尾 B。例如 A=12、B=32、C=4；新配對預設 r=1，兩片足長時比較 20 秒。長原片不用先裁切，選定片段最多 60 秒。
3. 確認後共同播放／拖曳，使用 ±10／50ms 與獨立鏡像微調。r 代表當時的固定跟跳比例，不是一起慢放；忽快忽慢不會自動對拍。片尾不足先顯示縮短，空交集禁止匯出。
4. 配方會保存；**兩個外部原片預設只在這次開啟**。「保存示範副本」與「保存自己影片副本」才複製，單檔初期限 200 MiB。重開缺片時逐側選回、預覽確認，不按同名自動配對。
5. 「調整區間／跟跳速度」建立另一個 take，舊配方與輸出保留；微調／鏡像增加目前配方版本，舊 VS 會標為不是目前配方。匯出後另存單一影片，離開本站重播核對聲音與方向。

## 練習與錄影

1. 選本機示範；影片不自動上傳或複製，筆記建在此瀏覽器。
2. 點「標記當下時間」，再填筆記；時刻不受打字影響，可編輯、刪除與跳回。
3. 設 A／B、練習速度與鏡像，再開始循環。練習無 60 秒限制；錄影限 0.5／0.75／1×、最多 60 秒，錄後固定配方。
4. 開前相機並倒數錄影，不要求麥克風。停止、取消或切背景會釋放相機；中斷 chunks 可在重開後嘗試恢復，讀回成功才是可用影片。
5. 自拍偏移正值略過自拍開頭、負值略過來源開頭。共同滑桿校正兩側，canvas 顯示真正鏡像輸出。
6. 輸出單一 VS 影片時保持前景。完成的自拍及 VS 保存到 IndexedDB，也請另外下載，離開本站重開核對聲音與方向。

選單可重開筆記；缺片時重新選檔、預覽、確認連結，不依檔名自動配對。「保存示範副本」是明確選擇，初期限 200 MiB；移除副本不刪筆記或原始檔。

JSON 備份只有筆記、媒體清單與配方，**不含影片**。匯入先驗證並顯示預覽，整份原子寫入；相同內容重匯冪等，相同 ID 不同內容拒絕整份，保留本機資料。衝突另存副本尚未實作。

首次載入並備妥靜態資源後可離線重開；媒體只有保存副本才能自動取回。更新不強制重載。瀏覽器可能清除資料，請另存影片與 JSON。

已測 Chrome 合成資料流程，不等於真實相機、Safari 或 G1–G7 全部通過。完整速度／時長矩陣、真實輸出同步、十次長錄影、完整資料管理、quota／migration 矩陣、5 人易用性、獨立 review 及發布仍待完成。現有檢查包含 Web 全模組的 TypeScript checkJs、獨立 Service Worker 型別環境、Biome lint、建置與邏輯測試。

播放器補驗：桌面 Chrome 156 已實播 H.264 靜音／直向／旋轉／VFR、H.264 MOV 及改名的有效 MP4。錯誤檔不取代原片與筆記，重新選同一檔案也能重試。HEVC／HDR、Safari 與手機仍未驗證，見 [#6 證據](evidence/issue-6-local-player.md)。

錄影新增前／後鏡頭選擇與全身取景框；缺少後鏡頭會提示，不自動換方向。新錄影依速度規劃 15–60 秒，「準備下一段」可修改設定，已保存的舊段保留。倒數取消不換掉原自拍；可播放的中斷片段也持續標示中斷，保存失敗時請立即下載原片。這些軟體保護仍需真實相機與中斷驗收，見 [#9 證據](evidence/issue-9-capture-recovery.md)。
