# 桌面 Web 預覽

### Cloudflare 的 PR 測試網址

Cloudflare 使用根目錄 `wrangler.jsonc`：先跑既有建置，再只上傳 `dist/web`。不能直接上傳 `web` 或用 `file://` 開原始碼；這兩種方式沒有完整建置的離線 manifest、授權與回應政策。

檢查設定可執行 `npx wrangler versions upload --dry-run`；經使用者授權後，以 `npx wrangler versions upload --preview-alias pr-90` 建立 PR 預覽，使用命令回傳的 HTTPS URL。這不切換正式部署，勿用 `wrangler deploy` 代替。不同網址各自保存瀏覽器筆記，預覽資料不會自動出現在正式站；影片仍只在本機選取。

使用者於 2026-10-27 指定先做 Web，暫不處理 iPhone。此版提供可操作的桌面流程，未公開發布，未完成整體 P0 驗收。

2026-10-28 桌面實作已提供「比較已有影片」入口，包含老師課後片＋自己已錄好的片、各自選起點、不開相機、共同對齊及 VS 輸出，見 [產品流程 B2](PRODUCT_PLAN.md)。原先收在測片選單的自拍選檔已改為直接顯示「我的已錄影片」。手機與其他瀏覽器仍依實測範圍列支援。

「影片與練習筆記」分開兩種日常操作：點「選擇硬碟影片（MOV／MP4 等）」開始，或選已保存的筆記、點「開啟筆記」繼續練習。找不到原片時會請你重新選取並預覽確認。影片是 MOV／MP4 原檔；筆記是文字、時間標記與對齊設定，兩者不是同一個檔案。

需要搬家或分享時，展開「備份、分享與管理筆記」。「匯入筆記 JSON（分享／備份）」只用於筆記檔，所以選該入口時 MOV／MP4 會變灰；影片請用上方選片按鈕。完整帶到另一台裝置需另帶影片原檔，沒有自動打包成一個檔案。舊版備份相容說明也收在此工具區。能否播放仍依瀏覽器實際解碼結果判斷，桌面合成驗證與未驗證範圍見 [#89 證據](evidence/issue-89-video-picker.md)。

### 直接比較兩支已錄好的影片

1. 點「比較已有影片」，選上方示範影片與「我的已錄影片」。兩片預設只在這次開啟；沒有相機或麥克風權限也能完成。
2. 分別播放，找到同一個動作，按老師／我的「當下畫面設為起點」，並選老師結尾；也可在秒數欄輸入。預設原速 1×。自己的起點沿用偏移欄，例如老師 12 秒、我 4 秒；變更比較片段會另存設定，不修改原片。
3. 用 ±10／50 毫秒微調與兩側獨立鏡像，點「一起預覽」。可「一起暫停」後拖共同時間線，再繼續預覽。鏡像請看下方左右合成畫面，原生控制文字不翻轉。
4. 點「輸出單一 VS 影片」。合成會從共同區間起點重新開始，預設只使用老師聲音；老師沒有音軌時輸出無聲。首版選定片段最多 60 秒，長原片不會被裁切。
5. 下載老師原片、自己的原片、VS 與 JSON 備份。想重開自動取回兩片時，分別按保存示範／我的影片副本；每份副本初期限 200 MiB。沒有保存副本也能保留配方，重開時逐側選片、預覽並確認連結。

修改設定或更換原片後，舊 VS 保留且顯示需重新匯出的提示。JSON 只含配方與媒體描述；還原到另一個瀏覽器後必須另外取得兩支原片。

### 邊播邊錄與共用功能

使用 Bun 1.4.4 先執行 `bun install --frozen-lockfile --ignore-scripts`，再執行 `bun run dev`，在此電腦開啟 `http://127.0.0.1:4173/`。`bun run build` 產出 `dist/web/` 靜態檔，不需要 API key、帳號或後端。

1. 選本機示範；影片不自動上傳或複製，筆記建在此瀏覽器。
2. 點「標記當下時間」，再填筆記；時刻不受打字影響，可編輯、刪除與跳回。
3. 設 A／B、練習速度與鏡像，再開始循環。練習無 60 秒限制；錄影限 0.5／0.75／1×、最多 60 秒，錄後固定配方。
4. 開前相機並倒數錄影，不要求麥克風。停止、取消或切背景會釋放相機；中斷 chunks 可在重開後嘗試恢復，讀回成功才是可用影片。
5. 自拍偏移正值略過自拍開頭、負值略過來源開頭。共同滑桿校正兩側，canvas 顯示真正鏡像輸出。
6. 輸出單一 VS 影片時保持前景。完成的自拍及 VS 保存到 IndexedDB，也請另外下載，離開本站重開核對聲音與方向。

選單可重開筆記；缺片時重新選檔、預覽、確認連結，不依檔名自動配對。「保存示範副本」是明確選擇，初期限 200 MiB；移除副本不刪筆記或原始檔。

JSON 備份只有筆記、媒體清單與配方，**不含影片**。匯入先驗證並顯示預覽，整份原子寫入；相同內容重匯冪等，相同 ID 不同內容會在預覽中標示，明確選「另存衝突副本」才新增另一份，原資料保留。不同來源會分開匯入，相同備份重匯不重複新增。

首次載入並備妥靜態資源後可離線重開；媒體只有保存副本才能自動取回。更新不強制重載。瀏覽器可能清除資料，請另存影片與 JSON。

已測 Chrome 合成資料流程，不等於真實相機、Safari 或 G1–G7 全部通過。既有影片的完整固定比例／時長矩陣、實際成檔逐格同步及十次 60 秒輸出已驗證，見[既有影片證據](evidence/existing-comparison.md)。相機路徑完整矩陣及十次長錄影、完整資料管理、quota／migration 矩陣、5 人易用性、獨立 review 及發布仍待完成。現有檢查包含 Web 全模組的 TypeScript checkJs、獨立 Service Worker 型別環境、Biome lint、建置與邏輯測試。

接手見[交接紀錄](HANDOFF.md)，重現測試見[驗證說明](MEDIA_PROBE.md)，結果見[證據](evidence/web-preview.md)。

播放器補驗：桌面 Chrome 156 已實播 H.264 靜音／直向／旋轉／VFR、H.264 MOV 及改名的有效 MP4。錯誤檔不取代原片與筆記，重新選同一檔案也能重試。HEVC／HDR、Safari 與手機仍未驗證，見 [#6 證據](evidence/issue-6-local-player.md)。

錄影新增前／後鏡頭選擇與全身取景框；缺少後鏡頭會提示，不自動換方向。新錄影依速度規劃 15–60 秒，「準備下一段」可修改設定，已保存的舊段保留。倒數取消不換掉原自拍；可播放的中斷片段也持續標示中斷，保存失敗時請立即下載原片。這些軟體保護仍需真實相機與中斷驗收，見 [#9 證據](evidence/issue-9-capture-recovery.md)。

#9 與正式既有雙片入口的整合版另見 [整合證據](evidence/issue-9-comparison-integration.md)。它保留錄影恢復及原片保護，同頁可在兩個入口間切換；歷史分支的成檔矩陣仍維持各自版本歸屬。

### 帶走備份與重新連結影片

1. 展開「備份、分享與管理筆記」，點「下載筆記備份」帶走 JSON，並檢查自動打開的「影片副本與重新連結」。JSON 不含影片；示範、自己原片與 VS 都可分別另存。清單會分辨本機副本、本次連結與缺片，瀏覽器副本仍需另外備份。
2. 還原時先看來源影片、將新增的筆記與衝突數量，再選確認或取消。需要時另存衝突副本；不會以新舊時間猜誰可以覆寫誰。相同副本重匯會跳過。
3. 缺片旁按「選片並預覽重連」，看內容與時間，勾選確認。預設只在這次連結，想重開自動取回再明確保存副本；同名檔不自動配對，短於已存比較結尾的老師片不可連結。
4. VS 可獨立重連並另存；它不能代替老師／自己的原片來繼續編輯比較。重連不換掉當下另一組比較畫面；從對應影片筆記開啟即可取回配方。

同名筆記會顯示第幾份，實際標題與筆記原文不變。匯入或保存失敗時保留原資料與候選，可取消、備份或重試；另一分頁更新後需先保留草稿再重新開啟。桌面證據見 [#12 驗收](evidence/issue-12-backup-recovery.md)，不宣稱手機恢復已驗證。

### 離線、容量、更新與移除資料

展開「離線、容量與更新」，按重新檢查核對應用資源及估計容量。首次在線備妥後先重開一次，確認頁面受離線服務控制；離線前也看影片保存清單，只有保存副本才能重開自動取回。未存原片可從裝置重新選片。第一次離線開站不支援，顯示完整也不是永久保存保證。

「請求瀏覽器持久保存」會如實顯示允許、未允許或失敗；任何結果都要另存 JSON 與影片，容量估計不是裝置剩餘空間或寫入承諾。儲存失敗／取消會保留上次資料。

有新版時只顯示等待，不中斷錄影或匯出。先另存筆記、原片與輸出，再關閉所有本站分頁後開啟；目前開著但沒保存的原片要重新選取。資源不完整的新版不會取代舊版。

保存清單可只移除一支瀏覽器副本；練習列表可分別刪單一 VS 或練習與比較；影片選單可刪整份筆記。先看確認視窗內的標題與數量，預設焦點為取消。整份筆記會連同所屬標記、練習與比較資料刪除，共用原片仍有其他練習使用時保留。只移除副本不刪配方，原相簿和原始檔也不會刪除；需要的資料請先下載。


### 鍵盤與放大文字

可先用頁首「跳到選片與錄影」，Tab 移動、Enter／空白啟用原生按鈕，方向鍵調整數字與滑桿；在筆記欄打字不會啟動播放。保存、編輯及確認框結束後會留在適合接續操作的位置；主動移到停止鍵時不搶走焦點。各播放器有不同的可讀名稱，狀態不會逐影格反覆宣告。

長狀態保留全文，可捲讀；停止列保持可用，控制會依文字大小換欄。本輪測過 Chrome 的鍵盤／可及性樹與十組 viewport／文字尺寸，不代表已完成讀屏實聽或手機觸控。五人獨立操作仍待依 [觀察操作單](WEB_USABILITY_CHECK.md)執行；沒有把自動化當真人結果。

## 動作庫與分類搜尋（#17 桌面候選）

1. 開啟影片筆記，填課程老師／舞風／日期，按「儲存標題」一併保存；缺片仍能填分類、看原筆記。
2. 展開「分類搜尋與動作庫」，新增動作並手選「想練／練習中／會了」。到標記的編輯表單，選「所屬動作」；不同影片可選同一動作。
3. 用關鍵字、舞風、老師、日期範圍及狀態篩選。動作下可開指定片段，歷史列出涵蓋該片段的 take，按「開啟這次比較配方」沿用原有對齊設定。缺片時先重連老師／自己的原片，再開同一入口。
4. 狀態只由你修改。編輯片段範圍或解除關聯會改變歷史清單，原 take／配方不刪；移除動作前會預覽影響，確認後只解除分類，原片與標記保留。
5. 新版保存與備份採 v2，可還原 v1；舊版無法讀 v2。升版前請用舊版保存 v1 備份並另存影片；要回復舊版，在另一環境還原舊備份，現有 v2 資料保留。JSON 仍不含影片。

首次備妥應用資源後可離線搜尋／改狀態／看歷史；影片需要已保存副本或重新選原檔。本票未宣稱 Safari／手機、真人驗收或公開發布通過，版本證據見 [#17](evidence/issue-17-moves.md)。

### 手動 BPM 與八拍

在「練習與時間筆記」展開「手動 BPM 與八拍」，填原速音樂 BPM，找老師原片的第一拍並按「老師當下畫面設為第一拍」，再保存。老師播放位置與標記旁會顯示八拍組和拍號；修改後要保存才套用，取消會取回原設定。沒有可靠 BPM 可移除拍點，照常使用秒數。

錄影可選 4／8 拍（含提示音）或上方 3／5／10 秒倒數。拍數倒數跟上方錄影速度放慢；老師停在 A，倒數後才起播，不自動調整 A。請先保存或取消拍點編輯再錄影；錄影中控制鎖定。拍點跟 JSON 筆記備份，不改原片或既有比較；JSON 仍不包含影片。固定 BPM 不追蹤歌曲變速，自動偵測不在本版。


動作表單有未保存內容時，切換其他動作會提示先「儲存動作」或「取消動作編輯」，原輸入保留。保存失敗仍可整理草稿；離頁會提示尚有未保存內容。這是本次頁面的保護，不承諾關機或程序崩潰後復原未保存草稿。
