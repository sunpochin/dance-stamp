# 桌面 Web 預覽

使用者於 2026-10-27 指定先做 Web，暫不處理 iPhone。此版提供可操作的桌面流程，未公開發布，未完成整體 P0 驗收。

2026-10-28 桌面實作已提供「比較已有影片」入口，包含老師課後片＋自己已錄好的片、各自選起點、不開相機、共同對齊及 VS 輸出，見 [產品流程 B2](PRODUCT_PLAN.md)。原先收在測片選單的自拍選檔已改為直接顯示「我的已錄影片」。手機與其他瀏覽器仍依實測範圍列支援。

### 直接比較兩支已錄好的影片

1. 點「比較已有影片」，選上方示範影片與「我的已錄影片」。兩片預設只在這次開啟；沒有相機或麥克風權限也能完成。
2. 分別播放，找到同一個動作，按老師／我的「當下畫面設為起點」，並選老師結尾；也可在秒數欄輸入。預設原速 1×。自己的起點沿用偏移欄，例如老師 12 秒、我 4 秒；變更比較片段會另存設定，不修改原片。
3. 用 ±10／50 毫秒微調與兩側獨立鏡像，點「一起預覽」。可「一起暫停」後拖共同時間線，再繼續預覽。鏡像請看下方左右合成畫面，原生控制文字不翻轉。
4. 點「輸出單一 VS 影片」。合成會從共同區間起點重新開始，預設只使用老師聲音；老師沒有音軌時輸出無聲。首版選定片段最多 60 秒，長原片不會被裁切。
5. 下載老師原片、自己的原片、VS 與 JSON 備份。想重開自動取回兩片時，分別按保存示範／我的影片副本；每份副本初期限 200 MiB。沒有保存副本也能保留配方，重開時逐側選片、預覽並確認連結。

修改設定或更換原片後，舊 VS 保留且顯示需重新匯出的提示。JSON 只含配方與媒體描述；還原到另一個瀏覽器後必須另外取得兩支原片。

### 邊播邊錄與共用功能

使用 Bun 1.4.4 先執行 `bun install --frozen-lockfile --ignore-scripts`，再執行 `bun run dev`，在此電腦開啟 `http://127.0.0.1:4173/`。`bun run build` 產出 `dist/web/` 靜態檔，不需要 API key、帳號或後端。

1. 選本機示範；影片不自動上傳或複製，筆記建在此瀏覽器。
2. 點「標記當下時間」，再填筆記；時刻不受打字影響，可編輯、刪除與跳回。
3. 設 A／B、練習速度與鏡像，再開始循環。練習無 60 秒限制；錄影限 0.5／0.75／1×、最多 60 秒，錄後固定配方。
4. 開前相機並倒數錄影，不要求麥克風。停止、取消或切背景會釋放相機；中斷 chunks 可在重開後嘗試恢復，讀回成功才是可用影片。
5. 自拍偏移正值略過自拍開頭、負值略過來源開頭。共同滑桿校正兩側，canvas 顯示真正鏡像輸出。
6. 輸出單一 VS 影片時保持前景。完成的自拍及 VS 保存到 IndexedDB，也請另外下載，離開本站重開核對聲音與方向。

選單可重開筆記；缺片時重新選檔、預覽、確認連結，不依檔名自動配對。「保存示範副本」是明確選擇，初期限 200 MiB；移除副本不刪筆記或原始檔。

JSON 備份只有筆記、媒體清單與配方，**不含影片**。匯入先驗證並顯示預覽，整份原子寫入；相同內容重匯冪等，相同 ID 不同內容拒絕整份，保留本機資料。衝突另存副本尚未實作。

首次載入並備妥靜態資源後可離線重開；媒體只有保存副本才能自動取回。更新不強制重載。瀏覽器可能清除資料，請另存影片與 JSON。

已測 Chrome 合成資料流程，不等於真實相機、Safari 或 G1–G7 全部通過。既有影片的完整固定比例／時長矩陣、實際成檔逐格同步及十次 60 秒輸出已驗證，見[既有影片證據](evidence/existing-comparison.md)。相機路徑完整矩陣及十次長錄影、完整資料管理、quota／migration 矩陣、5 人易用性、獨立 review 及發布仍待完成。現有檢查包含 Web 全模組的 TypeScript checkJs、獨立 Service Worker 型別環境、Biome lint、建置與邏輯測試。

接手見[交接紀錄](HANDOFF.md)，重現測試見[驗證說明](MEDIA_PROBE.md)，結果見[證據](evidence/web-preview.md)。

播放器補驗：桌面 Chrome 156 已實播 H.264 靜音／直向／旋轉／VFR、H.264 MOV 及改名的有效 MP4。錯誤檔不取代原片與筆記，重新選同一檔案也能重試。HEVC／HDR、Safari 與手機仍未驗證，見 [#6 證據](evidence/issue-6-local-player.md)。

錄影新增前／後鏡頭選擇與全身取景框；缺少後鏡頭會提示，不自動換方向。新錄影依速度規劃 15–60 秒，「準備下一段」可修改設定，已保存的舊段保留。倒數取消不換掉原自拍；可播放的中斷片段也持續標示中斷，保存失敗時請立即下載原片。這些軟體保護仍需真實相機與中斷驗收，見 [#9 證據](evidence/issue-9-capture-recovery.md)。

#9 與正式既有雙片入口的整合版另見 [整合證據](evidence/issue-9-comparison-integration.md)。它保留錄影恢復及原片保護，同頁可在兩個入口間切換；歷史分支的成檔矩陣仍維持各自版本歸屬。
