# 練舞介面檢查

按本次改動畫面檢查，不為套用設計目錄而重做產品。正式驗收以 [驗收計畫](../ACCEPTANCE.md) 與 [Web 操作清單](../WEB_USABILITY_CHECK.md) 為準。

- 從使用者任務走一遍：選片 → 練習 → 錄影或選已有影片 → 校正 → 單一 VS 下載。每一步有可理解的主要動作與返回／取消方式。
- 初次使用、空清單、載入、成功、失敗與重試都要看；讀取錯誤和保存錯誤分開，不能把未確認保存顯示成成功。
- 檢查窄畫面、橫直方向、縮放、長標題與錯誤文字。停止按鈕保持可見，鏡像不翻轉控制文字，播放器不能擠掉必要操作。
- 用鍵盤操作選片、對齊、確認與取消，確認焦點可見且回到合理位置；觸控操作不依賴 hover，按鈕有可理解的文字，狀態不只靠顏色。
- 使用既有元件與樣式保持標籤、間距及互動一致，不硬套別的框架、字型套件或醫療指標配色。繁體中文文案依產品需求，不自動新增強制多語規則。
- 取消或失敗後，舊影片、筆記及可下載輸出仍能使用；UI 顯示完成須對應真正的操作結果，不能只看動畫或 Promise 結束。

記錄受測版本、畫面尺寸、輸入方式、預期與實際結果，並查看 console 錯誤。自動化瀏覽器與模擬尺寸只證明受測環境；觸控、讀屏、聽感與裝置編碼沒測就寫未驗證，不替代媒體驗收。
