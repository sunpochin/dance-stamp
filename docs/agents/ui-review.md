# 練舞介面的專用檢查

一般鍵盤、觸控、焦點、版面及錯誤狀態先用 [awm-frontend-review](../../skills/awm-frontend-review/SKILL.md)。再把同一本手冊用到下面的練舞流程，就不必在這裡重抄通用清單。

- 走完選片 → 練習 → 錄影或選已有影片 → 校正 → 單一 VS 下載；數值門檻依 [RECORD_COMPARE.md](../RECORD_COMPARE.md)。
- 錄影時停止按鈕保持可見；鏡像不能翻轉控制文字；播放器不能擠掉停止與必要操作。
- 取消或失敗後，依產品契約保留舊影片、筆記及可下載輸出；保存未確認不能顯示成功。
- 繁體中文文案依產品需求，不自動新增強制多語。正式驗收以 [驗收計畫](../ACCEPTANCE.md) 與 [Web 清單](../WEB_USABILITY_CHECK.md) 為準。
- 模擬尺寸、合成媒體與自動化瀏覽器不代替觸控、讀屏、聽感或實體裝置驗收；沒測就記未驗證。
