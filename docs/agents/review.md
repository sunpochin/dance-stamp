# 練舞產品的審查與交接

先用 [awm-review-evidence](../../skills/awm-review-evidence/SKILL.md) 整理審查與版本收據，再按下面核對練舞產品。這樣共用方法只維護一份，產品驗收仍有自己的標準。

- 審查影片／筆記保全、資源釋放、取消、時間映射與交換格式；具體數值與驗收條件引用 [RECORD_COMPARE.md](../RECORD_COMPARE.md)，不另訂門檻。
- 本專案同一方向連續兩次有意義修正仍失敗，就重新檢查假設與根因，必要時交使用者或獨立審查者判斷，依 [工作流程](workflow.md)。
- 媒體、音訊、備份與裝置結果按 [驗收範本](acceptance-template.md)，只公開匿名摘要與合成素材；缺設備或未測就記未驗證。
- 自動化、獨立審查、裝置驗收、合併與發布分開記錄。重大變更由 Claude Code 或使用者審查；合併與發布依根 [AGENTS.md](../../AGENTS.md) 的明確授權，不由共用 skill 放行。
