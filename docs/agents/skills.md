# Skill 使用與維護

把共用方法當成一本固定版本手冊，產品規則當成本專案的補充頁。先按任務挑 skill，再讀直接相關的補充，不必把全部內容載入。

- 共用 v0.1.0 的完整副本、入口與更新方式見 [共用方法](work-methods.md)。五個 `awm-*` 都指向 repo 內同一份原版內容。
- `repo-onboarding` 與 `frontend-review` 是保留舊名稱的本產品薄入口，通用正文只引用 `awm-*`；`media-evidence`、`eli5-teacher`、`prime-directive` 保留產品驗收、解說偏好與本地憲法接線。
- 產品補充依 [程式慣例](code-conventions.md)、[審查](review.md)、[介面檢查](ui-review.md) 與 [工具邊界](skill-security.md)。
- 新增工具前先用 [awm-skill-safety](../../skills/awm-skill-safety/SKILL.md)；完整必要相依與授權一起入 Git。使用者要求與根 [AGENTS.md](../../AGENTS.md) 優先，共用方法不新增發布、寄信、讀秘密、排程或派工授權。
