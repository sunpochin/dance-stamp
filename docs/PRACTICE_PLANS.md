# 課後練習計畫 Practice Plans

[#259](https://github.com/sunpochin/dance-stamp/issues/259) 是 P1 提案，尚未排入實作。以下描述預期行為及未來要做的測試。

舞者在課後打開自己有權使用的示範片，圈出想練的幾段，選每天有幾分鐘。按「產生計畫」就能預覽一週的安排，滿意才儲存。隔天按「開始」就回到那一段，照自己的速度反覆練，最後自己記下感受。老師不必出題、開帳號或批改。

## 從一支影片到本週任務

1. **選段。** 一份計畫使用一支老師影片。可從區間標記帶入 A、B，也可手動圈選。只有時間點的標記要由舞者補 B。所有片段以原片整數毫秒保存，須符合 `0 ≤ A < B ≤ 影片長度`。空清單、反向或越界都指出是哪一段，保留已填內容。
2. **排程。** 標題、開始日、目標日與每日可用時間隨計畫保存。預設從本地今天排連續七個日曆日，可縮短至一天，目標日計入，上限七天。預設每日五分鐘，可選十分鐘或自訂正整數分鐘。日期按日曆日處理，跨月、跨時區重開仍顯示原排定日期。分鐘是當天所有任務的預算。
3. **產生草稿。** 依選段順序先單段熟悉，再成對複習，最後一天重溫所選片段。四段 A、B、C、D 的七日例依序為 A／B／C／D／A＋B／C＋D／A＋B＋C＋D。同日每段各有一個任務，按秒均分當日預算，剩餘秒數從第一項依序各加一秒。每個任務只循環自己的 A/B，兩段中間的畫面不會被加入。一段就每天重複該段，一天就直接預覽所選各段的複習。最後一天固定複習所有選段；之前的日子先依序一天一段，排完一輪後才從頭按相鄰兩段一組輪替，落單的一段單獨練。如果時間太短，仍可在最後一天看到所有選段。若某段連以原速完整播放一次都超過分到的時間，標出該段並讓舞者調整片段或預算後再儲存。產生不靠 BPM 或動作辨識。
4. **預覽與修改。** 顯示每個日期、段名、A/B 與預估時間。可改日、調序、調整時長、移除任務，或取消整份草稿。只有明確儲存才建立計畫，重按不多建一份。之後可重排待練任務，保留既有回報；過期的待練任務可自由改日或跳過。
5. **開始與回報。** 今日清單和整週清單都可從正常的桌面 Web 入口返回。當原片可用，點任務一次即自 A 開始循環，可調練習速度、鏡像、暫停及退出。播放失敗或瀏覽器要求再按播放時，保留選段與任務並提供重試。在比較、錄影、匯出或未保存編輯中切換，應保留工作並提示先完成或取消原操作。開啟任務、變速和退出都不得改寫比較配方。
6. **回看進度。** 待練、完成、跳過由人選擇，可更正。每個任務只計一次，保存最後回報時間和可選的簡短自評／改善筆記，重按完成或重載不重複計次。歷史可看到任務、排定日期和實際回報時間。漏一天保留原紀錄。第一版不量測實練分鐘，也不由播放、錄影或 VS 匯出推斷完成或「會了」。

## 保存與恢復

| 情境 | 提案要求 |
| --- | --- |
| 標記變更或刪除 | 計畫保存段名、影片 ID 及 A/B 快照；標記 ID 只是來源線索。提示原標記已變更或刪除，播放仍使用已確認的快照。若要改練別段，由舞者明確編輯待練任務。已回報的歷史保留原段與日期。 |
| 缺片或選錯片 | 計畫仍可閱讀與改日。禁止只靠檔名配對。循既有流程預覽並人工確認來源，候選無法涵蓋任務 B 時不得啟動或偷偷截短該任務；取消或解碼失敗保留原連結與紀錄。 |
| 主動刪除 | 移除本機影片副本可保留計畫。明確刪除整份影片筆記則先列出受影響的計畫、任務和回報數量，一起確認或全部取消。刪計畫不連帶刪老師原片、其他筆記、take 或配方。刪除已有回報的任務前須提示歷史影響。 |
| 本機與匯入 | 沿用 IndexedDB 的 metadata 與 revision 交易。同次保存計畫、任務、回報須一起成功。完整 JSON 帶這三者及來源關聯，影片另存。規劃新版完整備份讀取 v1/v2，舊資料得到空計畫；舊程式遇新版應拒絕。現行 v2 會重建已知欄位，不能直接追加計畫後繼續標 v2。備份格式版本與 IndexedDB 的資料庫版本分別評估。 |
| 合併與失敗 | 依既有匯入流程預覽衝突、保留副本並同步改寫影片、計畫、任務與回報 ID。重複匯入同一份檔案不應多出一套歷史。無效日期、未知版本、斷裂的必要參照及越界資料在寫入前拒絕。容量不足、取消或另一分頁搶先寫入時保留舊資料與可重試內容；交易結果未確認時依既有救援流程讀回。 |
| 私密範圍 | 舞者不用登入，計畫與自評預設只在本機。只有明確下載的完整筆記備份會帶它們。既有選段分享、Google 選定練習快照和成品觀看連結均排除計畫、每日安排與自評。顯示匯入文字只作純文字。 |

## 待驗收案例

| 案例 | 通過條件 |
| --- | --- |
| 排程與編輯 | 用合成老師片及四個不相鄰區間重現七日例，核對同輸入產生相同順序、每日分鐘總和、手動改日／刪除及取消。另驗單點未補 B、片尾、單片段、僅一天、跨月和預算放不下。 |
| 舞者入口 | 從正常首頁只選老師片即可建計畫；鍵盤可預覽、儲存與開始。驗 A/B、慢速、鏡像、暫停、離開與錯誤重試。用另一份已有比較的資料，核對切換前後配方、原片及 VS 可取回。 |
| 回報與接續 | 一項完成並填自評、一項跳過、一項錯過再改日。重複按完成，關閉再重開，核對日期、狀態、計數與筆記。修改／刪除來源標記後仍能練原區間。 |
| 備份與隱私 | 新環境還原完整 JSON，逐筆比對計畫／任務／回報，再人工重連合成原片。驗舊備份、同 ID 衝突保留副本、重匯、錯片、短片、刪除取消。檢視分享檔與雲端候選內容，確認不含任務名稱或自評。 |
| 故障與驗證 | 注入 quota、取消、兩分頁競寫、未知版本或壞資料，讀回原資料與原片；無交易收據時先救援再讀回。實作 PR 須附純邏輯、桌面瀏覽器回歸、`bun run check` 與受測版本。Safari、實體手機、真實課堂影片分別列出證據或「未驗證」。 |
