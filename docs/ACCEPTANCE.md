# 驗收與風險清單

本文件所有項目都是待驗證。沒有執行紀錄、影片或數據時不得勾為完成。使用自製時間碼／提示音測片及經允許的實拍；公開紀錄不放私人課程影片。

## 1. 支援矩陣

先記錄測試當時精確 OS／瀏覽器版本與機型，再決定最低支援版本；不在沒有設備證據時寫「支援所有 iPhone」。

| 平台 | 優先級 | 要驗證的路徑 |
| --- | --- | --- |
| iPhone Safari，一台主要機型及一台較舊機型 | 核心 | 選片、邊播邊錄、對齊、合成、保存、重開、容量不足 |
| iPhone 加入主畫面模式，同兩台機型 | 核心 | 同上，加離線／更新／獨立儲存狀態驗證 |
| macOS Safari | 核心 | 本機影片、相機、合成、音訊與下載 |
| 桌面 Chrome | 核心 | 完整流程、鍵盤、資料恢復與多分頁 |
| Android Chrome，中階實機 | 次要 | 核心流程與輸出相容性；iOS 問題優先處理 |
| Firefox／其他裝置 | 擴充 | 先標記未驗證，通過才列支援 |

Playwright WebKit 是自動化回歸工具，不等於實體 iPhone Safari 的相機、硬體解碼、音訊路由與檔案保存。模擬相機可測流程，不能取代真機 gate。

## 2. 測試素材

- 小型 H.264/AAC MP4、無音軌 MP4、直橫向、左右 L/R 字樣與移動時間碼。
- 來自自有 iPhone 的 HEVC/MOV、帶旋轉資訊、可變影格率、HDR 樣本；能播放與不能播放的組合都記錄。
- 15／30／60 秒閃光＋提示音參考片，用於同步與漂移量測；非授權音樂不進 repo。
- 相同檔名但不同內容、重新命名相同影片、截短版本、損壞／空檔、不支援格式。
- JSON：正常、重複、衝突、未來版本、孤兒關聯、巨大內容、惡意 HTML／危險鍵。
- 媒體檔 20／100／200 MiB 作初始保存矩陣；更大選片模式另測，不能宣稱等同可永久保存。

## 3. 自動化應覆蓋的行為

| 類別 | 驗收 |
| --- | --- |
| 時間與配方 | 點／區間邊界、offset 正負值、慢速映射、空交集、極端值；與 [RECORD_COMPARE.md](RECORD_COMPARE.md) 範例一致 |
| Marker | 點標記的當下取時間；變更／刪除後索引一致；切片不誤改來源時間 |
| A–B | 0.5×／1×／2×、快速切換區間、影片結尾、手動 seek、背景恢復；無重複 seek 洪水 |
| 資料 | migration 成功與失敗、交易回滾、quota 寫入失敗、多分頁 revision 衝突、缺檔保留筆記 |
| 交換 | 匯出再匯入內容一致、再匯入冪等、衝突另存重寫關聯、未來版本拒絕、分享欄位篩選 |
| 媒體生命週期 | 取消／失敗／離頁釋放 object URL、callback、相機 track、AudioContext；不重複掛節點 |
| 網路 | 核心操作無媒體／筆記對外請求，無第三方追蹤；離線失敗可理解 |
| UI | 主要流程、權限拒絕、空狀態、錯誤恢復、匯出取消與重試 |

只寫能抓到資料遺失、錯誤時間映射與壞輸出的測試，不為每個純文字標籤另寫鏡像實作的測試。

## 4. 真機 gate

同步／成檔 gates 完整定義在 [RECORD_COMPARE.md](RECORD_COMPARE.md)，本文件不另訂第二套數字。基本播放器還要測：

- 測片可播放時，點擊標記後實際顯示位置與目標誤差目標 ≤150ms；記錄 codec 與設備，不把它當逐格保證。
- A–B 連續 20 次回捲，不卡死、不漏停、不逐次擴大延遲；每次越過 B 的媒體時間目標 ≤150ms（依受測能力決定正式支援範圍）。音訊無縫循環不在 P0 承諾。
- 取景保留全身，左右鏡像與輸出一致；手機直向／橫向和 safe area 不遮停止／保存按鈕。
- 來源聲音只出現一次，藍牙與喇叭各測；麥克風未授權仍可完成預設錄影比較。
- 來電／鎖屏／切背景／相機被占用／旋轉中斷有可理解結果，停止所有 track；受損輸出不標成成功。
- 下載檔離開 app 後重新開啟，在受測手機與桌面播放器核對容器、音軌、方向、時長。記錄存到 Files／相簿／系統分享的實際能力，不混稱。

## 5. 資料安全演練

### 既有影片比較（P0，2026-10-28 補充；全部待驗證）

以 [RECORD_COMPARE.md](RECORD_COMPARE.md) 的既有影片入口與共同映射為唯一時間契約，桌面先行，手機未測仍標記未驗證。#10／#11／#12 分別收錄對應證據：

- 無相機裝置、相機／麥克風拒絕或未授權時，能從「比較已有影片」完成兩片選取、對齊、VS 匯出；全程沒有媒體擷取權限請求，也沒有影片／音訊對外上傳。
- 左老師／右自己，各自預覽並選起點；合成片驗證老師 12 秒／自己 4 秒起跳，含正負微調、不同片長、片尾不足與空交集。預設 r=1 不繼承上次慢速值，手動固定比例依專項規格；不能用固定 offset 掩蓋持續漂移。
- 同步播放／暫停／拖曳，等待兩側 seek 完成；獨立鏡像、完整全身與共同時間線在預覽及匯出一致。選長原片但限制比較片段的流程清楚，原片不被裁切。
- 老師有音軌時只輸出該音軌，自己片的音軌不重疊；老師無音軌時顯示無聲並驗證成檔。檔案離開網站仍可重播，按專項規格收 G2–G5、G7 及選片路徑 G6 證據；不以此代替錄影 G1。
- 任一側取消選檔、空檔、損壞或不支援格式，舊配對／筆記／輸出仍可用；重試同一檔有效。更換成功後不誤用舊配方，舊輸出保留且不冒充新配方結果。
- 兩片預設當次開啟，主動保存副本才複製。重開或 JSON 還原後缺任一片，保留對齊／鏡像設定、逐側預覽確認；同名不同片、裁切版本不得自動配對。JSON 不含影片，原片須分開保存。
- quota／多分頁衝突／匯出取消不丟失既有資料；外部選片不出現假的 recording 或相機中斷恢復。至少一次完成兩片配對、JSON 往返與媒體重連的完整演練。

### 共用恢復演練

1. 建立 3 支合成影片、10 個 marker、兩個 take 及一個 VS 輸出。
2. 匯出 JSON，另存示範、自拍及 VS 檔，記下數量與識別。
3. 在獨立測試瀏覽器資料夾清除網站資料；不操作使用者的正式資料。
4. 重新安裝／載入、匯入 JSON、重連媒體，核對筆記、配方、鏡像與時間線。
5. 缺一個媒體檔時顯示 missing；其他筆記正常，不錯配同名檔。
6. 模擬 quota、匯出取消、migration 中斷；舊資料仍可用或能從備份恢復。

瀏覽器持久化請求不取代這個演練；只匯出 JSON 未保存媒體不能宣稱「完整恢復成功」。

## 6. 易用性與隱私

主要觸控按鈕目標至少 44×44 CSS px；鍵盤可控制播放／標記／loop，輸入框打字不觸發快捷鍵。控制有可讀名稱、焦點提示、對比與非顏色狀態；螢幕閱讀器能讀出錄影與保存狀態，更新頻率不持續洗版。

相機權限拒絕後有重試說明，程式不循環彈窗。錄影指示與停止按鈕保持可見，結束後設備指示燈熄滅。分享／診斷內容先預覽，預設不含私人筆記、老師姓名或原檔名。資料刪除清楚區分筆記、離線副本及輸出。

## 7. 發佈判定與證據格式

每筆驗收留下：commit、裝置／OS／瀏覽器、fixture 識別、步驟、預期／實際、時間／同步數據、匿名化輸出範例、pass/fail/未驗證、相關 issue。測不到的項目不可用推測補 pass。

發佈阻擋：P0 資料遺失、私密媒體外傳、手機核心錄影／輸出未完成、音畫不同步超過門檻、既有資料 migration 破壞、授權不相容依賴。P1 動作庫或分享未完成不阻擋 P0。

Web gates 失敗時按平台決策切到 iOS，iOS 仍須通過同一份使用者流程與資料恢復要求；不能因原生 API 名稱看似可行就宣告通過。

## 8. P1 檔案分享（#18）

此節驗證 [DATA_FORMAT.md](DATA_FORMAT.md#6-分享格式p1) 的第一版檔案流程，維持 M4／P1，不新增 P0 發佈門檻。以下全為待驗證；目前只有規劃，沒有實作或真機結果。

- 選定片段及欄位，預覽後匯出 `kind=share`；未選的私人筆記、老師、原檔名、拍攝日期及無關 take 不出現在筆記檔，只有主動加入的欄位可包含。
- 筆記檔明示不含影片；示範原片與 VS 檔分開保存，接收者已有相同原片時只傳筆記也能完成配對。另傳影片的畫面、聲音及內嵌資訊不受 JSON 欄位篩選保護，提示須正確。
- 另一裝置匯入後重建 ID 關聯、保留既有資料，人工預覽確認影片後跳到選定片段；同名不同片、裁切／轉碼版本與誤選 VS 檔不自動當成原片。
- 缺少影片時保留筆記並提示選檔，不宣稱雲端連結可播放；取消、匯出失敗、壞檔或匯入失敗不刪原片及既有筆記，可重試。
- 未設定雲端帳號或系統不支援分享時，下載檔案／選檔匯入仍可完成。外部雲端額滿、權限不符或連結失效時可改用一般檔案傳送，不要求付費升級，不把本機匯出標成已送達。
- App 內的匯出／匯入沒有影片或筆記對外上傳、雲端 OAuth／API 呼叫或上傳中繼；使用者另行開啟雲端服務傳檔所產生的網路活動分開記錄。
- 分享前說明已下載副本不能遠端撤回；停止雲端連結分享不顯示為已刪除接收者的檔案。

以合成筆記及影片記錄下列途徑的寄件與接收裝置、OS／瀏覽器版本、實際步驟和結果；雲端登入及權限由測試者自行操作，紀錄不含帳號、憑證或私人連結。

| 途徑 | 要驗證的操作 | 狀態 |
| --- | --- | --- |
| 一般檔案 | 匯出後搬到另一裝置，選檔匯入、重連、跳到片段 | 未驗證 |
| Google Drive | 使用者自行存入個人空間並分享，接收者下載檔案後匯入 | 未驗證 |

## 9. #19 手動拍點

以自製 120 BPM／第一拍 0.35 秒的圖樣與 660Hz 短聲測片驗證，禁止商用音樂或私人影片。核對 0.5／0.75／1× 同一來源拍號、第一拍前、1／8／下一組 1 的邊界、暫停／seek／循環與標記；拍數倒數跟錄影速度而非練習速度。音訊以 OfflineAudioContext samples 獨立量測提示音起點、間隔、頻率及取消；錄影以合成相機驗證鎖定、倒數取消、中斷及秒數備援，不冒充實體相機。

保存／重開、JSON 乾淨環境還原、重匯、衝突副本、舊備份缺欄、無效／極端輸入、metadata quota／取消及 revision 衝突均保留原資料與草稿；另跑既有 migration 回滾。原片前後 bytes 相同，提示音不接 VS 音軌，錄影與配方時間定義不改。真人修正拍點、實聽、音訊路由、Safari 與真機仍需各自證據，iPhone 暫緩。結果綁定版本見 [本票證據](evidence/issue-19-manual-beats.md)。
