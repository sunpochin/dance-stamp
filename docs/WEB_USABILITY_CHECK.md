# Web 易用性觀察操作單

本單尚未執行，不代表已有受測者或結果。先測桌面 Web；iPhone 依使用者要求暫緩。五人觀察、真實相機／音訊、讀屏實聽與 Playwright 分開記錄，任何一項都不能代替其他項目。

## 先用一組真實影片開始

這一步讓你先知道「拿自己的影片來練」是否順手，不必一次找齊五人。它是五人觀察前的個人試用；結果不能代替後面的正式條件。

### 只提供影片，Agent 可接著做

準備同一小段舞的兩支原片：一支示範、一支練習，各約 20–30 秒即可先做短流程。兩片保留頭、手、腳，包含可辨識的同一動作，以及快腳步或轉身；兩次不必跳得一模一樣。一般室內光線、衣服／背景接近或拍攝距離／角度不同的原片，也能補查色塊測片看不出的問題；保留原有片頭等待、直橫向和拍攝格式，不必先裁切或轉檔。若方便，可再提供一支至少 65 秒的原片，供後續長片檢查；短片不代表 60 秒 gate 通過。

素材由本人拍攝或取得同意，先避開旁人及私人課程。可不拍臉，使用自製拍手／節拍或無音樂；若原片含你有權使用的音樂，也只在本機處理。告知兩個本機檔案位置及允許本機測試的範圍即可，不必上傳影片；不要將原片或原檔名放入公開 issue／PR。

Agent 收到明確指定的素材後，可在隔離環境檢查選片／解碼、標記重播、不同起點、變速、獨立鏡像、疊影大小與位置、單一 VS 下載及網站外重播、備份／逐側重連；核對原檔未改且沒有產品對外媒體請求。公開只記匿名格式、量測和結果，原片及成檔留本機。

真人兩次動作本來就可能不一樣；用同一動作選起點可檢查流程，不能拿舞者的反應差當成軟體同步誤差。精確同步仍用 [RECORD_COMPARE.md](RECORD_COMPARE.md) 的同一量測方法與門檻。快速動作的可辨識程度及聲音是否自然仍需本人看／聽確認。兩次舞步若自然忽快忽慢，固定起點或速度不會自動校正每一步；應觀察使用者能否理解這個限制。

### 需要本人操作或判斷

| 情境 | 先做的最小操作 | 觀察重點 |
| --- | --- | --- |
| 課後回看與反覆練 | 在真實示範選一個動作、寫筆記、重播一小段，試原速與慢速 | 能否回到正確動作；是否容易找出拍點與左右腳 |
| 兩支現成影片比較 | 各選同一動作作起點；試並排、鏡像、疊影及身體大小／位置，再下載 VS | 能否看出自己要改哪個動作；取景距離不同時疊影是否有幫助；VS 保持並排，疊影調整只影響疊影框 |
| 站離螢幕跟跳並錄影 | 本人點開相機，先做 15 秒；完成、停止與取消各一次 | 全身與腳是否入鏡、倒數是否夠走回位置、停止鍵是否找得到、結束後相機指示燈熄滅 |
| 真正聽拍 | 用電腦喇叭、再用平常的藍牙設備聽同段原片／慢放／VS | 拍點、聲畫、音高及是否重複混音；解碼成功不能代替聽感 |
| 真實中斷與離線 | 先另存測試資料，再切背景／鎖屏／停網；回來重開原筆記與影片 | 不自動恢復錄影，原片／舊 VS 保留；只處理專用測試環境，不動日常網路或資料 |
| 第一次使用與讀屏 | 依下方三項目標由舞者自行操作；有需要者實際聽讀屏 | 記錄提示、卡點與退出；Agent 代操作及可及性樹不算真人成功 |

試用後可補一句「我從比較中發現哪個動作要改」，再重練並找回同一標記，觀察是否真的幫助練習。這是質性回饋，不新增分數、學習成效承諾或正式通過門檻。

先完成短流程，再按既有規格補三速度 × 15／30／60 秒，以及同裝置連續十輪 60 秒「錄影 → 匯出」。完整矩陣、裝置保存、熱／電池及中斷結果分開填，不將短片或單輪推廣為全部通過。iPhone 目前仍暫緩，Android 為後續範圍；不要求先買設備。

## 準備與同意

由五位自願舞者各自操作同一個待驗收版本。先說明可隨時停止，只記匿名回饋，不做背景追蹤、錄屏、收音或自動上傳。觀察者可以協助開啟網站、提供已授權的本機素材及說明測試目的；不可替受測者完成核心步驟，任何操作提示都要記錄。

使用專用瀏覽器測試資料，保留既有使用者資料。素材須為自製或經明確同意的練舞片，包含能辨識同一動作的老師／自己的兩片；不用第三方音樂或私人課程內容作公開證據。相機與保存由操作者明確點按，不預先自動開啟。測後若要清理，先由本人確認已另存，僅使用產品內的個別刪除，不清除別人的儲存。

先記版本／commit、日期、裝置型號、OS、瀏覽器版本、輸入方式，以及影片容器／codec。不要記姓名、帳號、裝置序號、相機 label／deviceId、原始檔名或課程名稱。原片、錄影與私密檔案識別留在操作者裝置；公開只保留匿名化摘要。

## 給受測者的三項任務

只讀下列目標，不提示按鈕位置或操作順序。

1. 在老師影片中記下想重看的動作與一段筆記，稍後回到那個位置播放。
2. 跟著老師影片錄下自己的練習，調整到同一動作，再帶走一支可在網站以外播放的左右比較影片。
3. 你已經有老師與自己的兩支影片。讓同一個動作對齊，再帶走一支左右比較影片，全程不需要重新錄影。

觀察找到入口、閱讀狀態、誤選／取消、微調、保存及外部重播時的困惑。若需要提示，先記下卡點，再協助繼續；有提示完成須另列，不算獨立成功。不設定新的時間或媒體門檻。

## 觀察者核對

- 任務 1：標記與原片時間歸屬正確，文字保留，跳轉後確實看到對應動作。
- 任務 2：明確開相機、可停止，結束後相機釋放；保留原片，手動校正與鏡像符合預期。
- 任務 3：能找到既有雙片入口、各自選同一動作起點，沒有請求相機／麥克風。
- 任務 2、3：真正下載單一 VS，在產品外重開，核對左右、方向、長度與老師聲音；不能只記下載按鈕成功。有無音軌依實際素材記錄，不把無音軌當聲音成功。
- 同步、成檔及完整媒體驗收仍依 [RECORD_COMPARE](RECORD_COMPARE.md) 的同一 G1–G7，不另設門檻；人說看起來正常不代替逐格／音訊證據。
- 輔助觀察：能否區分 JSON 與影片、找回保存資料；鍵盤／觸控／讀屏各自記錄，放大文字與橫直向不遮停止鍵。不得將 viewport 或 AX tree 當實體觸控／VoiceOver 實聽。

使用 [驗收範本](agents/acceptance-template.md) 記錄每次設備與媒體結果。發現缺陷時先保留匿名步驟、預期／實際及受測版本，另連對應 issue；不重置資料來掩蓋問題。
