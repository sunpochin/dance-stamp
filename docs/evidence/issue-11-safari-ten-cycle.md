# Safari 一般視窗：十輪錄影與 VS 成檔對照

## 怎麼用、為什麼有效

這次像連續拍十次、每次都把原片和左右比較片存好，再重新開同一頁點名：十次都有新檔，兩次讀回的完整筆記與二十二份影片內容也相同。這能證明這一輪沒有只顯示「完成」卻拿到舊檔；不能保證所有環境都不會再失敗。

工程對照採一般 Safari、同一分頁，選合成示範和練習片；每輪準備新 take、A＝0／B＝60 秒／1×／3 秒倒數，原片完成後在 B 後試播 1.5 秒，再合成。實際參數與每輪原始收據都有保存。日常遇到中止時仍須先另存原片與可下載的舊 VS、保留錯誤紀錄；本頁不是要求舞者靠反覆十輪測試排除故障。

- 每次按錄影或合成後，以原生捲動將示範帶回可見區。這與原調查的控制方式、觀察器及可見性條件不同，並非只改一個因素的隨機對照。
