# 單側結果成功後顯示正確提示（#200）

## 怎麼用、為什麼有效

框到空白或製片失敗時，可以保留原片與筆記，在同一頁重新框選或更新結果。成功後上方會說「老師跟隨影片已完成」或「自己跟隨影片已完成」，不再一邊顯示新影片，一邊留著前次失敗訊息。取消與真正失敗仍會告訴你原因，舊成果保留。

像影片已做好，負責報消息的人卻還拿著上一張失敗紙條；現在由兩個入口共用的成品交付點通知主畫面。只有新檔確實交換成功才換提示，不在開始操作時先宣稱完成。
