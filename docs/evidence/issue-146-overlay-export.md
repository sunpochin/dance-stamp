## 自行審核與失敗保留

第一輪新測試嘗試 fetch(blob:) 被既有 CSP 拒絕，該輪失敗照實保留；改從已提交 Blob 讀 bytes 再核對真正下載，不放寬 CSP。自行審查另發現疊影會留在共用左右畫布，已在 stream 停止後還原預覽，並加像素回歸。舊可讀名稱原本只指左右，改成兩種共用的比較播放器，既有可及性斷言同步更新。人工檢查完整 diff、快照、外觀保存／分享／取回、取消／錯誤與舊片保全。這是同一 Agent 的自行審核，不冒稱獨立人工審查。
