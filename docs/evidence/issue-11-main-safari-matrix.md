# #11：固定 main 的雙片 Safari 聲畫續驗

## 先用白話說

把兩支自己做的測試影片選進工作台，存成一支比較影片，再真正下載。這次讓示範片每秒發出提示音，對照畫面上的時間碼，檢查「看見這一秒」與「聽到這一秒」是否對齊。所有素材均為合成資料，沒有使用相機、麥克風或私人影片。

1× 與 0.75× 的 15 秒成片通過本輪檢查。0.5× 的成片能完整解碼、兩側畫面同步，但聲音量尺偵測到多餘事件，當次即停止，沒有繼續跑長片或十輪。原檔、失敗、操作失誤與設定收據都保留；目前不能說半速聲畫或整體 Safari 已通過。

四份真正下載的檔案，包含設定失配的額外檔案，都在原網站與主機關閉後，以 Safari 新檔案視窗自然播放到尾。這只證明這些檔案能獨立播放，沒有推翻半速的聲音量測失敗，也沒有人工聽感結論。

- 每份實際下載逐 bytes／SHA 對照瀏覽器媒體，FFmpeg 以原固定的 `-xerror`、`-fps_mode passthrough`、`-enc_time_base:v demux` 完整解碼全部軌；要求 exit 0 且 stderr 空。沿原 G2／G3、v5 覆蓋、完整長度及聲源門檻，不改錄製器或解碼器。

示範片沿用原 80 秒、320×180 的雙片時間碼影像，僅替換為自製 660 Hz 提示音：每秒前 0.5 秒發聲，AAC-LC／48 kHz；編碼後視訊封包 hash 與原合成示範片完全相同。新示範檔 SHA256 為 `d4bf3ab496d9b148e0e58a5f9644a2d8c91a783e1fea72597f0d6e9252838efd`。三支練習片沿原對應速率時間碼與 880 Hz 聲源，未改影像。

新增獨立凍結聲音 QA 量尺以真正像素秒界線對照保留 PTS 的 PCM；沿既有 v5 的 10 ms RMS 區塊、0.03 閾值、`0.25 / rate` 分組、半開區間與 100 ms 順序配對，不採產品時鐘代替成檔。輸入 80 個提示音的校準最大差 0 ms；產品執行前，五個正例（原速、兩種慢速、鏡像、無聲）接受，音軌延後 500 ms 與缺中間提示音兩個負例拒絕；原雙片量尺也接受五個新正例。聲音 QA 程式 SHA256 為 `5399df7f10f9f2c8876a64a9953523fbc66a3f89b22a2bd9284cb9851fcd09ba`，仍屬本輪調查工具，尚未交付為正式回歸入口。

## 實際結果與停止點

各案示範起點 A＝12 秒、練習片起點＝4 秒，B＝A＋速度×15 秒；並排、不鏡像、未啟用人物跟隨。每份均由產品按鈕匯出，再由 Safari 原生另存對話框下載。

| 實際配置 | 雙側全影格最大差 | 最長停格 | 提示音配對 | 結果 |
| --- | ---: | ---: | --- | --- |
| 1×／15 秒 | 33.333 ms | 114 ms | 15／15，最大差 46 ms | 本輪量尺通過 |
| 0.75×／15 秒 | 44.444 ms | 117 ms | 12／12，最大差 78 ms | 本輪量尺通過 |
| 0.5×／15 秒 | 66.667 ms | 149 ms | 畫面 8 個、分組後聲音 11 個 | 聲音量尺未通過，停止 |

三份完整解碼皆 exit 0／stderr 空，原雙片量尺通過；片長約 15.02 秒、平均約 30 fps。表內全影格差保留量測值，G2 仍採原首／中／末與漂移判定，沒有新增或放寬標準。前兩案按下匯出至 ready 分別 15,333／15,312 ms；沒有執行 60 秒配置，不能宣告 G7 通過。前兩案匯出區間的被動樣本均在前景且有焦點；來源播放器當時在可視範圍外，該欄原樣保留，不能宣稱有來源可見性對照。

半速的原始聲音 onset 為 13 個，原分組規則後為 11 個。事件數不相同時，不能把錯位 zip 配對所算出的秒級差解釋為真實聲音延遲。保持原失敗，不更改分組或做固定補償來取得綠燈。

另有一次 QA 設定失誤：更換右片的現有流程會重設速度為 1×、起點為 0；操作在選片前設定 0.75×，之後只重設起點，誤產生 1×／11.25 秒檔。原快照 005／006、設定失配下載與完整收據保留，不列入正確 0.75× 通過。確認 `self-file` 原處理順序後，後續改為先選兩片、再設定，並在每次匯出前核對已保存快照與原生控制值。正確 0.75× 使用 007／008，半速使用 009／010；十輪序列尚未開始。這是 QA 操作修正，沒有改產品重設行為。

## 尚待查明與下一步

離線讀同一份半速下載，在保留 PTS 與連續 PCM 兩種解碼中均能看到額外閾值交越；48 kHz 左右聲道也有短暫振幅降低。標準工具從同一 AAC 輸入建立的半速波形，在排除提示音起訖邊界後沒有這些 10 ms 低音量區塊。

這仍不足以定位至 Safari AAC 解碼、Web Audio 重採樣或 Opus 錄製；也不足以宣告人耳可聽到斷音。原 RMS 分組對長提示音中的短暫振幅降低敏感，尚未校驗為可直接判斷斷音的量尺。下一步先隔離原生 AAC 解碼後的真正 PCM，再與相同來源／區間的標準 PCM 對照；保留原未通過結果與凍結量尺，不重跑直到綠燈，也不以固定延遲補償冒充根因修正。

30／60 秒、十輪連續兩片選擇、無聲／鏡像配置仍未執行。實體相機與麥克風、人工聽感、真機、耗電／溫度／記憶體峰值、離線與完整 G1–G7 均未驗收。本輪沒有合併、發布或關閉 #11。
