# #95 左右選片與練習流程

2026-10-30 Asia/Taipei；從 main `f3333a0` 建獨立分支。僅使用合成影片，未讀取私人影片或操作實體相機。本輪 Web 靜態版本為 `85774dbb5fc59379`；證據對應此版本，未合併或發布。

## 使用者結果

- 左卡「選老師影片（左）」只開老師欄位，右卡「選我的影片（右）」只開自己的欄位。選片與對應播放器同卡，載入後顯示角色及秒數。
- 先載入老師筆記才開放右片；兩支已錄好的影片不要求相機。相機設定另收在「還沒錄好？邊看老師邊錄下我的練習」。
- 選片、對齊、保存先行；筆記、備份、搜尋、影片副本與離線狀態移到下方，頁首可直接跳到舊筆記。
