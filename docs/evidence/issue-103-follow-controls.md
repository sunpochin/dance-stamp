# #103 人物跟隨開關與清除保全

## 怎麼用、為什麼有效

框選完成後，取消「啟用老師／自己跟隨裁切」會暫時看回完整畫面；重新勾選就使用原本的找人結果，不必再分析一次。兩側各自控制，不應改動另一側。

「清除老師選框」會移除這次選框與追蹤，但先前做好的單側影片仍可用「匯出上次老師跟隨影片」另存。要做新結果須重新框選；舊 VS 也仍保留。開著框選視窗時按 Escape，應關閉視窗並回到原本的框選按鈕，讓鍵盤操作可以接下去。

這次只補現有功能的檢查，沒有改產品。像真的開關燈後看房間亮不亮：除了看勾選狀態，還直接比對實際預覽畫面，並在清除前後真正下載檔案核對內容。

## 範圍與來源

- 從同步主線 `148f5845d52a9433dcd97274feb45edb35e40c79` 建 `codex/issue-103-follow-controls`。
- 沿用 `person-follow`、真正預設介面、本機人物模型與既有合成影片。未新增情境名稱、改變完整輪的 78 案順序，或改動原媒體期限及數值斷言。
- 十四份產品 JS、原插樁計數器與分母不變；未帶入尚待審查的 #194／#200 產品變更。
- 素材為虛構人物與合成聲音，禁止測試擷取相機／麥克風；沒有使用或上傳真人影片。

## 補測契約

1. 兩片載入後保留真正未裁切畫面，再完成兩側分析。逐側以公開 checkbox 暫停：該半邊須與未裁切畫面一致、與原裁切確實不同；另一半邊不變。重新啟用須回到兩側原裁切，兩份單側下載連結不變。
2. 開啟老師選框後用真正 Escape 按鍵觸發瀏覽器 dialog cancel。視窗關閉、焦點回老師入口、舊追蹤像素仍相同。
3. 保留原本取消分析、空白人物失敗、超出已分析區間、壞檔與逐側換片檢查。完成後清除老師選框：老師回到完整畫面、勾選／清除／更新結果皆停用，另一半邊像素與自己結果提示不變。
4. 老師舊單側結果標示「上次／先前」，兩份單側連結及舊 VS 連結不變；清除前後各從真正下載入口取得檔案，完整長度及 SHA-256 相同。

像素比對沿用既有鏡像回歸的每 channel 一階色彩捨入容許值；同時要求該側至少 100 個採樣 channel 確實改變，避免空畫面或無效開關也過關。只比較圖像區域，不把文字標籤當裁切證據。

## 首次補測失敗的處理

第一版在清除前用 `fetch(blobURL)` 取指紋，遇到 `TypeError: Failed to fetch`。原 CSP 的 `connect-src 'self'` 沒開放 Blob fetch，而 `media-src 'self' blob:` 允許影片播放；這次測試選錯讀取入口，未證明舊影片遺失。

改由清除前後的真正下載取檔，不修改 CSP、產品或原門檻。首次失敗的原日誌／收據保留；不把中途已通過的開關與 Escape 檢查當整案成功。
