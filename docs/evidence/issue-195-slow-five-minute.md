# #195 慢速五分鐘續驗

## 白話使用與驗法

老師片選 0–150 秒並設 0.5×，或選 0–225 秒並設 0.75×，都應產生完整 300 秒比較。自己的片沿共同時間原速走 0–300 秒；這個比例用於自己當時跟著慢速示範練習的配對。兩片各有自己的碼表，量測時先換成同一條共同時間。

真的按下載後，先確認檔案與網站保存內容完全相同，再關掉產品與自有主機、斷網，從檔案自然播到結尾。能下載或播放器顯示五分鐘，都不能代替完整影音驗證。

## 量尺取捨與保留的工具失敗

沿既有 v5 的原 100ms 同步／新增漂移／覆蓋、250ms 凍結／來源時鐘與最低 24fps。兩支原始碼表片需把老師碼除以 r、自己碼除以 1，再比較共同時間；既有短矩陣的自己片事先嵌入老師碼，輸入模型不同，不能直接套用。慢速內部聲畫事件數依老師來源秒數推導為 149／224，逐事件仍守原 100ms，首中尾摘要取真正第一、最接近中段及最後事件。

長片量尺原來源 SHA256 `50989508dda201e7d82c5b9295fa3960cf716469465eb3fb87a51e0433246534`，本輪沿原門檻調整輸入模型後為 `7f4b0c183431b1866f16259c556ee56e04579d1cc09e52572c4f09f178b1a5fd`；受測單速案例 SHA256 `2d5708dc6e0840de7883205a5dab68b6c1304e32bda3ea07e61eacdec6ea6a2d`，離站播放器沿原 `download-playback.js`／SHA256 `737e4be2d69c9f6c60da1c20c73754558b8d4b2416793bfaa989bc5a2c7c2ba1`。未提交工具的逐行差異與各次 hash 留 `analyzer-diff.local.patch`／`analyzer-provenance.local.json`；公開產品與原分析器均未改。

每種速度先用相同來源與明確映射直接編碼已知正控制，再把正控制音軌單獨延後 250ms 作負控制；不是產品輸出，也不是將成片時間戳改到通過。產品下載不裁切、不改時間戳、不重新編碼。

0.5× 只做一次產品長輸出。保留首輪預設 FFmpeg null 輸出精度產生六筆重複 DTS 警告（exit 0）的失敗；同檔沿既有量尺用 `-fps_mode passthrough -enc_time_base:v demux` 重驗 exit 0／stderr 空，原始成檔影格 PTS 另逐格驗證嚴格前進。也保留舊量尺誤用預先對齊時間碼而拒絕，以及固定 ±1 秒摘要窗在半速首提示略晚於 2 秒時成為空集合的工具錯誤；摘要失敗前逐事件數值斷言已執行。修正工具後只重讀同一下載，沒有重做長輸出或覆寫原失敗。一次續驗碰到另一個持鎖者即退出，未啟動媒體，等自然釋放再續驗。

兩案均在關閉全部產品頁與自有主機後，於新的專用瀏覽器設定離線、攔截 HTTP，再從真正下載的 `file:` 開啟，僅回到片頭後用原生按鍵自然播放；沒有快轉、跳到尾端或虛報 ended。兩案已知自有 Chrome PID 均退出，主機停止且各自 nonce 鎖釋放；原片的完整 hash 再核對不變。

所有原始收據、工具版本／差異、完整下載及獨立 profiles 留本聊天 ignored `output/issue195-slow-five-minute/`。公開摘要不含 profile、nonce、原生程序識別、內部連線或私人素材。舊原速 `850b3d2` 的 13 dropped 與舊量尺前置失敗保持原版本歸屬，不重跑改標。
