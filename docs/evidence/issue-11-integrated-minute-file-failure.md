## 小朋友也能懂的讀法

拿兩支會顯示時間碼、發出提示音的合成影片做比較，像用拍手檢查畫面與聲音有沒有對上。15秒與30秒的三種速度都在原標準內；第一支一分鐘影片有一次聲音先到，超過原標準，所以停下來保留它，繼續找原因。

讀這份紀錄時，先核對受測版本和檔案指紋，再分別看「品質」與「播放」。下載後離開網站，直接打開原檔確認能播完；另外用成片裡的畫面時間碼與聲音量時間差。這樣才能分清楚「檔案可讀」與「動作、聲音有對上」，也保留失敗檔供後續判斷。
