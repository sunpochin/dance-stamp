## 2. 怎麼稱呼與理解

對外稱「免費、非商用、原始碼公開／source-available」。OSI 的 open source 定義不允許限制商業使用，因此不用「完全開源」徽章或文字造成誤會。[OSI 定義](https://opensource.org/osd)。

PolyForm Noncommercial 授權允許非商用使用、修改與分發，並明列個人及教育、公益等組織的允許用途。它有自己的定義，不等於「任何涉及金錢的場景一律違法」；具體判斷以 [授權原文](https://polyformproject.org/licenses/noncommercial/1.0.0) 為準。專案不提供另購商用版本，也不建立商用授權銷售流程。

「個人下課後複習」是目標情境；付費課程中使用、舞蹈教室服務、公司內部培訓、含廣告的代管等邊界不能由 README 自行修改標準授權來解釋。遇到實際個案應釐清適用條文，必要時請合格法律專業人士確認；不把這些疑問做成阻擋個人練舞的 UI 勾選流程。

## 3. 歷史與第三方權利

新的 LICENSE 不追溯撤回已合規取得舊版本的 GPLv3 權利。GPLv3 第 2 節說明符合條件的授權不可任意撤回；本次沒有清除 Git 歷史，也沒有宣稱舊內容忽然不能商用。[GPLv3 原文](https://www.gnu.org/licenses/gpl.en.html)。目前尚無產品程式，使現在轉換比日後有多位貢獻者時單純。

只對專案有權授權的原創內容採新授權。第三方依賴保留原授權；不能把 GPL 等第三方程式加上非商用限制再散布。建立骨架時審查每個確切版本及傳遞依賴，保存 NOTICE／來源／授權清單；FFmpeg 類元件需按實際 build 的 codecs 與配置判斷，不能只看外層 wrapper。

後續貢獻者須確認其原創貢獻按專案當時授權提交，並揭露第三方來源；不要求一份無需求的商用權利轉讓。若未來再改授權，重新檢查所有權利人同意，不憑 repo owner 身分重授他人著作。

使用者的影片、舞蹈教學、音樂、聲音與肖像不因匯入本工具變為 PolyForm。參考產品只用來理解需求，不複製其 UI 素材、程式或宣稱合作。匯出／分享前提示確認有權使用內容，公開 issue 只用合成或經授權的素材。

## 4. 完全免費如何成立

| 項目 | 策略 | 不承諾的部分 |
| --- | --- | --- |
| 使用費 | 所有功能免費，無廣告／訂閱／付費解鎖 | 不提供付費客服 SLA |
| 影片儲存 | 使用者自己的裝置與自行保存的檔案 | 硬碟無限、瀏覽器永不清除 |
| P1 分享 | 匯出／匯入檔案，使用者自行用 Google Drive、Dropbox、iCloud Drive 或 AirDrop 傳送；不提供自己的影片儲存服務 | 供應商免費容量／流量永續、分享連結永久可用或 App 可確認送達 |
| 轉碼／VS 合成 | 本機瀏覽器或必要時原生處理 | 無限算力、背景永遠不中斷 |
| 靜態 Web | 評估免費託管與可下載自架產物，無必需網域費 | 免費主機永續可用、無限頻寬 |
| CI | 精簡檢查與可在本機跑的同等指令 | 永久依賴任何供應商的免費配額 |
| 資料分析 | 自願回饋與可預覽診斷，不加追蹤 | 自動蒐集全體使用者行為 |
| iOS | 原始碼與功能免費；發佈成本獨立列出 | App Store 必然零成本 |

使用者仍需自己的裝置、儲存空間、電力和網路；這些不是軟體收費。免費主機政策改變時可停用公開入口，已下載備份仍可在可用的本機版本還原，不為維持服務偷偷引入付費依賴。

第一版分享不要求雲端帳號、訂閱或付費 API；個人雲端的免費方案在其可用容量及規則內只是選用傳送途徑，額滿時仍可使用本機檔案或 AirDrop，不引導使用者把升級當成 App 的必要條件。雲端的儲存、權限與傳輸由使用者及其選擇的服務處理；專案不代管影片或提供上傳中繼。靜態網站託管與影片儲存成本分開，分享格式及限制見 [DATA_FORMAT.md](DATA_FORMAT.md#6-分享格式p1)。

## 5. iOS 優先與零支出的衝突

若 Web 無法完成 P0，下一步是 iOS，不是先 Android。但 Apple Developer Program 官方目前列出每會員年度 US$99（地區價格可能不同），符合條件的機構才可能申請減免；非商用個人專案不能假設自動免費。[Apple 官方](https://developer.apple.com/programs/enroll/)。

因此分兩項驗收：iOS 技術可行性，以及一般使用者可取得的發佈方式。若維護者要求任何現金支出都為零，未確認有效免付費資格或既有可用會員前，不承諾 App Store／TestFlight 公開分發；先保留源碼與開發測試成果，清楚標示安裝限制。不能把自行編譯安裝說成一般舞者已可無痛使用。是否負擔年費／採其他合規分發方式是後續具體決策，不在本次申購。

## 6. 維護責任

每次發佈附支援裝置、已知限制、資料格式版本、備份說明及第三方授權清單。沒有測試設備的組合標記未驗證。若停止維護，保留下載與自架說明、匯出格式和最後可用來源；不保證永久公共雲端服務，也不以非商用之名省略安全更新。
