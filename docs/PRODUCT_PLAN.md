# 產品規劃：免費的個人練舞工作台

原規劃日期：2026-10-27；2026-10-28 補充並實作桌面既有影片比較。狀態：已有桌面預覽及雙片入口，本文件的完整功能、手機與使用者驗收尚未完成。產品決策以本文件為準；工程決策見 [TECHNICAL.md](../TECHNICAL.md)，工作狀態見 [ROADMAP.md](ROADMAP.md)。

## 1. 使用情境與成功定義

主要使用者是自己練 Salsa shine 的舞者：課後拿到 recap，想找到某個腳步，放慢看，架起手機照著跳，再看自己與示範差在哪。Bachata／雙人舞可以沿用筆記能力，但不在第一版加入雙人角色辨識或姿態評分。

第一版包含兩條 P0 故事：**選片 → 標記 8 拍片段 → 慢速循環熟悉 → 倒數錄影 → 並排檢查 → 微調對齊 → 存成 VS 影片 → 備份筆記**；以及 **選老師課後影片＋自己已錄好的影片 → 各自選起點 → 並排對齊 → 存成 VS 影片 → 備份配方**。第二條不要求相機權限或重新錄影。兩條都不要求登入、信用卡或付費服務。

2026-10-28 補充：第二條是使用者確認的既有影片比較需求，列入 #10／#11 的 P0 範圍。桌面已提供正式選片、對齊與成檔入口；[合成雙片證據](evidence/existing-comparison.md)涵蓋固定比例與時長矩陣，不取代手機、真實相機與使用者驗收。

成功不是影片收藏數，而是使用者能在一堂課後迅速重找到動作，並自行完成比較。以 5 位自願測試者做任務觀察：至少 4 位在無口頭指導下完成選片到標記重播、錄影到 VS 存檔，以及兩支既有影片到 VS 存檔三項任務；另記錄失敗原因，不啟用背景分析追蹤。

## 2. 固定原則

- 完全免費：所有核心功能開放，不計影片分鐘、不設會員層級、廣告與浮水印解鎖。
- 非商用原始碼公開：採 PolyForm Noncommercial；不再宣稱一般開源。軟體授權不會改變使用者影片的權利。
- 本機處理：影片、相機畫面、筆記與輸出留在裝置；沒有自動上傳、帳號、伺服器轉碼。
- 可以帶走：JSON 備份可讀、可驗證；原始影片／自拍與 VS 輸出可各別保存，網站停用後仍能取用已下載的檔案。
- Web → iOS → Android：先驗證手機 Web 完整流程。桌面成功不能代替 iPhone 成功；必要時先補 iOS 原生媒體能力。
- 優先完成使用流程：錄影比較與影片合成是 P0，動作庫、雲端同步、自動節拍等不能擠掉它。

## 4. 核心操作流程

### A. 首次選片與標記

首頁提供「開啟影片」「比較已有影片」「還原筆記」入口。選片後顯示影片、時間標記清單與一鍵標記。預設只開啟檔案供當次使用，清楚提示：「筆記會儲存；下次可能需要重新選擇影片」。使用者主動選「儲存影片副本到此裝置」才複製檔案。

新增標記先記下當下時間，再讓使用者填名稱，避免輸入過程影片繼續播放而記錯。編輯 A／B 時顯示片段長度；不合法區間阻止啟動，不偷偷交換使用者的設定。

### B. Salsa shine 邊播邊錄

選一個片段，先慢速練習，再點「錄下我」。錄影設定頁確認示範區間、速度、相機、兩側鏡像、全身是否入鏡。第一版錄影速度支援 0.5×／0.75×／1×，開始後鎖定；錄影中的 seek／循環／變速需停止本次 take 後再改。

單次練習目標 15–60 秒（以實際錄影時間計，慢速也算在內）。倒數後示範從 A 開始播放，相機記錄自己，到 B 自動停止。這個長度是先驗證可靠性的範圍，不是商業配額；更長影片可用筆記／播放器，長 take 另行驗證。

預設前鏡頭方便一邊看示範一邊跳；後鏡頭只在使用者切換且驗證成功時使用。站遠看不清楚與腳被裁掉比華麗時間軸更影響實用性：主要控制大、倒數清楚、影片預設完整 fit，錄影中不要求觸碰小按鈕。

### B2. 比較兩支已錄好的影片（P0，#10／#11）

1. 點「比較已有影片」，從相簿／檔案分別選「老師課後影片」與「我的練習影片」。在已開啟的老師影片旁也提供此入口；不必先錄一段或授權相機／麥克風。
2. 兩片各自實際載入、可播放後，確認左老師／右自己。更換任一片可取消或重試；新片成功且確認後才替換，保留舊筆記與配方，不靠檔名自動配對。
3. 各自播放定位同一個動作，點「以此為起點」，再選老師片段的結尾。起點可不同，例如老師第 12 秒對自己的第 4 秒；不要求先用別的剪輯工具裁片。
4. 進入共同播放／暫停／拖曳時間線，以 ±50ms／±10ms 微調對齊，兩邊可各自鏡像，完整顯示全身。預設兩片原速；已知跟跳使用慢速示範時，可手動設定既有固定速度，語意與限制見 [RECORD_COMPARE.md](RECORD_COMPARE.md)。不自動判斷節拍或動作差異。
5. 顯示可比較區間及長度，任一側片尾不足時先說明縮短；沒有重疊區間就提示調整。可選長原片，但本期比較／匯出的選定片段最多 60 秒，原片不被裁切或覆寫。
6. 確認後沿用 C 的 VS 輸出。預設只用老師影片音訊，自己的影片靜音，避免兩份音樂重疊；老師片無音軌時明示輸出無聲。兩片都只在本機處理，保存副本須明確選擇。

配方與兩支原片分開保存；重開、備份還原或缺片時沿用 D 的重新連結。現成影片流程完成不代表「邊播邊錄」完成，兩條都須各自驗收。

### C. 看比較與保存

錄完先保留自拍原始 take，或完成 B2 的兩片選取，再進入同一比較頁。左示範／右自己，可各別鏡像，拖動共同播放位置；提供 ±50ms、±10ms 微調和較大偏移滑桿。相機延遲或兩片起點差異需校正，不宣稱兩支影片天然精準同步。

確認後選「產生 VS 影片」。匯出畫面說明需要保持前景、顯示進度與取消。輸出必須是單一影片檔，重新開啟仍有兩個畫面與來源音訊。若格式只能在部分播放器開啟，先標示相容性，不能把副檔名改成 MP4 假裝轉檔。

### D. 重新開啟與備份

關閉後重開仍能看見筆記與 take 記錄；找不到影片時顯示「重新選取影片」，資料不消失。備份頁列出筆記、示範原片、自拍、VS 輸出哪些已下載；JSON 不含影片，必須明確寫出。

### E. 傳給舞伴（P1）

第一版分享採「選內容 → 預覽 → 匯出檔案 → 使用者自行傳送 → 舞伴匯入 → 預覽配對影片 → 開啟片段」。筆記檔不含影片，示範原片與 VS 輸出分開保存及傳送；舞伴已有相同影片時只需分享筆記。欄位預設去識別與匯入規則以 [DATA_FORMAT.md](DATA_FORMAT.md#6-分享格式p1) 為準。

使用者可自行用 Google Drive、Dropbox、iCloud Drive 的個人空間或 AirDrop 分享；雲端權限與傳送由使用者在該服務處理，Dance Stamp 不提供自己的影片儲存服務，也不代為登入、上傳或同步。系統分享入口依裝置能力提供，下載／選檔匯入是基線；免費雲端空間不足時可改用其他檔案途徑，不必購買空間才能使用 App。

沒有影片時仍能保存筆記並提示選檔，不宣稱分享連結能直接在 App 播放。App 匯出成功不等於檔案已送達；取消或失敗保留原片與筆記。雲端連結即使停止分享，也不能收回已下載副本。此為 #18 的 P1／M4 規劃，不改變 P0 範圍；手機存檔及跨裝置匯入仍待驗證。

## 5. 畫面與狀態

| 畫面 | 主行動 | 必須看得懂的狀態 |
| --- | --- | --- |
| 首頁／影片庫 | 開啟、比較已有影片、還原、重連 | 老師／自己兩側角色、未保存影片、已保存副本、檔案遺失、備份日期 |
| 練習播放器 | 標記、循環、錄下我 | 保存中／失敗、A–B 啟用、速度與鏡像 |
| 錄影準備 | 取景、倒數、開始 | 權限未給／拒絕、相機被占用、格式不支援 |
| 錄影中 | 停止 | 錄影時間、剩餘時間、相機啟用；不顯示假的「已保存」 |
| 比較與匯出 | 校正、合成、下載 | 未對齊、生成中、中斷、可重試、已驗證輸出 |
| 資料管理 | 備份、重連、刪除副本 | 用量是估計、瀏覽器可清除、筆記與影片分別計數 |

錄影權限拒絕時仍可使用筆記、播放器及 B2 的既有影片比較；B2 全程不要求相機／麥克風。這不代表 P0 邊播邊錄已完成，也不把「退回其他相機 App 手動錄影」算作 B 流程通過。
