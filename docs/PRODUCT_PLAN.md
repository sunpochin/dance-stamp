# 產品規劃：免費的個人練舞工作台

規劃日期：2026-10-27。狀態：提案，尚未實作。產品決策以本文件為準；工程決策見 [TECHNICAL.md](../TECHNICAL.md)，工作狀態見 [ROADMAP.md](ROADMAP.md)。

## 1. 使用情境與成功定義

主要使用者是自己練 Salsa shine 的舞者：課後拿到 recap，想找到某個腳步，放慢看，架起手機照著跳，再看自己與示範差在哪。Bachata／雙人舞可以沿用筆記能力，但不在第一版加入雙人角色辨識或姿態評分。

第一版完整故事：**選片 → 標記 8 拍片段 → 慢速循環熟悉 → 倒數錄影 → 並排檢查 → 微調對齊 → 存成 VS 影片 → 備份筆記。** 不要求登入、信用卡或付費服務。

成功不是影片收藏數，而是使用者能在一堂課後迅速重找到動作，並自行完成一次錄影比較。以 5 位自願測試者做任務觀察：至少 4 位在無口頭指導下完成選片到標記重播、錄影到 VS 存檔兩項任務；另記錄失敗原因，不啟用背景分析追蹤。

## 2. 固定原則

- 完全免費：所有核心功能開放，不計影片分鐘、不設會員層級、廣告與浮水印解鎖。
- 非商用原始碼公開：採 PolyForm Noncommercial；不再宣稱一般開源。軟體授權不會改變使用者影片的權利。
- 本機處理：影片、相機畫面、筆記與輸出留在裝置；沒有自動上傳、帳號、伺服器轉碼。
- 可以帶走：JSON 備份可讀、可驗證；原始影片／自拍與 VS 輸出可各別保存，網站停用後仍能取用已下載的檔案。
- Web → iOS → Android：先驗證手機 Web 完整流程。桌面成功不能代替 iPhone 成功；必要時先補 iOS 原生媒體能力。
- 優先完成使用流程：錄影比較與影片合成是 P0，動作庫、雲端同步、自動節拍等不能擠掉它。

## 4. 核心操作流程

### A. 首次選片與標記

首頁只有「開啟影片」「還原筆記」兩個主要入口。選片後顯示影片、時間標記清單與一鍵標記。預設只開啟檔案供當次使用，清楚提示：「筆記會儲存；下次可能需要重新選擇影片」。使用者主動選「儲存影片副本到此裝置」才複製檔案。

新增標記先記下當下時間，再讓使用者填名稱，避免輸入過程影片繼續播放而記錯。編輯 A／B 時顯示片段長度；不合法區間阻止啟動，不偷偷交換使用者的設定。

### B. Salsa shine 邊播邊錄

選一個片段，先慢速練習，再點「錄下我」。錄影設定頁確認示範區間、速度、相機、兩側鏡像、全身是否入鏡。第一版錄影速度支援 0.5×／0.75×／1×，開始後鎖定；錄影中的 seek／循環／變速需停止本次 take 後再改。

單次練習目標 15–60 秒（以實際錄影時間計，慢速也算在內）。倒數後示範從 A 開始播放，相機記錄自己，到 B 自動停止。這個長度是先驗證可靠性的範圍，不是商業配額；更長影片可用筆記／播放器，長 take 另行驗證。

預設前鏡頭方便一邊看示範一邊跳；後鏡頭只在使用者切換且驗證成功時使用。站遠看不清楚與腳被裁掉比華麗時間軸更影響實用性：主要控制大、倒數清楚、影片預設完整 fit，錄影中不要求觸碰小按鈕。

### C. 看比較與保存

錄完先保留自拍原始 take，再進入比較頁。左示範／右自己，可各別鏡像，拖動共同播放位置；提供 ±50ms、±10ms 微調和較大偏移滑桿。延遲需校正，不宣稱兩支影片天然精準同步。

確認後選「產生 VS 影片」。匯出畫面說明需要保持前景、顯示進度與取消。輸出必須是單一影片檔，重新開啟仍有兩個畫面與來源音訊。若格式只能在部分播放器開啟，先標示相容性，不能把副檔名改成 MP4 假裝轉檔。

### D. 重新開啟與備份

關閉後重開仍能看見筆記與 take 記錄；找不到影片時顯示「重新選取影片」，資料不消失。備份頁列出筆記、示範原片、自拍、VS 輸出哪些已下載；JSON 不含影片，必須明確寫出。

### E. 傳給舞伴（P1）

第一版分享採「選內容 → 預覽 → 匯出檔案 → 使用者自行傳送 → 舞伴匯入 → 預覽配對影片 → 開啟片段」。筆記檔不含影片，示範原片與 VS 輸出分開保存及傳送；舞伴已有相同影片時只需分享筆記。欄位預設去識別與匯入規則以 [DATA_FORMAT.md](DATA_FORMAT.md#6-分享格式p1) 為準。

使用者可自行用 Google Drive、Dropbox、iCloud Drive 的個人空間或 AirDrop 分享；雲端權限與傳送由使用者在該服務處理，Dance Stamp 不提供自己的影片儲存服務，也不代為登入、上傳或同步。系統分享入口依裝置能力提供，下載／選檔匯入是基線；免費雲端空間不足時可改用其他檔案途徑，不必購買空間才能使用 App。

沒有影片時仍能保存筆記並提示選檔，不宣稱分享連結能直接在 App 播放。App 匯出成功不等於檔案已送達；取消或失敗保留原片與筆記。雲端連結即使停止分享，也不能收回已下載副本。此為 #18 的 P1／M4 規劃，不改變 P0 範圍；手機存檔及跨裝置匯入仍待驗證。

## 5. 畫面與狀態

| 畫面 | 主行動 | 必須看得懂的狀態 |
| --- | --- | --- |
| 首頁／影片庫 | 開啟、還原、重連 | 未保存影片、已保存副本、檔案遺失、備份日期 |
| 練習播放器 | 標記、循環、錄下我 | 保存中／失敗、A–B 啟用、速度與鏡像 |
| 錄影準備 | 取景、倒數、開始 | 權限未給／拒絕、相機被占用、格式不支援 |
| 錄影中 | 停止 | 錄影時間、剩餘時間、相機啟用；不顯示假的「已保存」 |
| 比較與匯出 | 校正、合成、下載 | 未對齊、生成中、中斷、可重試、已驗證輸出 |
| 資料管理 | 備份、重連、刪除副本 | 用量是估計、瀏覽器可清除、筆記與影片分別計數 |

錄影權限拒絕時仍可使用筆記與播放器，但 P0 錄影比較未完成；不把「退回其他相機 App 手動錄影」算作本需求通過。
